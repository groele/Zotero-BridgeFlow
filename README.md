# Zotero BridgeFlow（桥引）

> 当前版本：**0.7.3** · 兼容范围：**Zotero `10.0` ~ `12.*`** · 协议：**AGPL-3.0-or-later**

</div>

**Zotero BridgeFlow（桥引）** 是专为 **Zotero 10 ~ 12** 打造的一体化科研读写工作台插件，在微内核架构之上深度融合了 **多标签阅读工作区**、**阅读可视化与条目简记**、**侧栏引文预览 / 反向逆查 / PDF 对照** 与 **Microsoft Word 写作引用追踪**，全面打通 **「多篇沉浸精读 ➔ 批注矩阵对比与简记沉淀 ➔ 即时引文检阅/反查 ➔ Word 写作引用追踪」** 闭环。

---

## 核心功能全景

### 1. 子系统一：阅读工作区与快速查找 (`workspace`)

- **双模标签工作区**：
  - 顶部水平分组标签栏（支持滚轮横向滚动、`compact` / `auto` / `normal` 三态紧缩、分组双击内联改名、颜色切换、拖拽成组与 `Compact Top Bar`）；
  - 左侧可调宽垂直侧边栏（支持 `分组` / `集合` / `状态` 三视图切换、快捷键导航、批量管理、拖拽排序、Word 引用序数徽标 `[1]` 与阅读进度条）。
- **三态标签生命周期与会话快照**：支持固定标签页、空闲自动/手动休眠标签释放内存、保留分组虚拟成员；支持手动快照、模板快照与自动滚动快照，并通过中心弹窗（Hub）执行期刊/会议智能归组与工作区 JSON 导出/导入。
- **Spotlight 全局命令与快速查找 (`Ctrl+P` / `Cmd+P`)**：
  - 打开即展示最近标签、Word 正在引用的文献、最近关闭标签、会话快照与分组；输入后按标题、作者、备注、分组检索，输入 `>` 进入命令模式（如直达分组、一键将 Word 正在引用的打开文献生成对比矩阵等）。
  - 列表高度自适应当前窗口剩余可视空间，防按键清空白闪。
- **高精度阅读计时与悬停预览卡片**：
  - 在主窗口聚焦、激活阅读器标签且未进入 3 分钟键鼠/滚轮/翻页无操作空闲时，每 15 秒及切页/关页瞬间结算停留秒数（单跳 `30s` 封顶防止系统休眠漂移），切页尾数精准归属至刚离开的旧标签与对应页码；
  - 悬停标签显示相对阅读时间、精确当前页与时长（支持 `<60s` 秒级展示）、峰值停留页（`最常停留 Pxx`）、标注数量与按页阅读热力条。

### 2. 子系统二：阅读可视化、画廊看板、状态评级与集中笔记中心 (`visual-notes`)

- 在「可视化与简记 → 画廊」可调整卡片最小宽度（140–440 px）和封面高度（0 为自动，最高 360 px），即时生效；PDF 封面以高纵横比整页缓存，拉高图框时自动展示更多首页内容且不左右裁切，摘要封面采用平滑渐隐遮罩，看板列宽同步响应卡片宽度设置。
- 画廊「笔记」仅列出已有简记或子笔记的文献。笔记中心支持为当前范围的文献补写简记。宽窗口通过左侧文献目录切换，窄窗口使用下拉框。标注按页码与语义标签组织，原文和评注分段显示，支持选中文字或复制整条。
- 笔记与标注中心默认在 Zotero 标签页中打开。在「设置 → Zotero BridgeFlow → 可视化与简记」勾选「在独立窗口打开中心」，下次打开时即使用独立窗口。

- **题名阅读热力图与五大文库列（状态 · 评级 · 阅读时长 · 标注分布 · 简记）**：
  - 将论文全篇划分为最多 16 个分桶，根据逐页累计停留时长生成相对强度渐变色条叠加渲染在 Zotero 主列表题名后（悬停即显示时长、进度与峰值停留页），支持自定义热力图基色、最大不透明度与选中行高亮反白，不修改 Zotero 原生题名字段；
  - 主文库支持按需开启 **「阅读状态」**（`/` 前缀彩色胶囊，支持不破坏多选的批量指派、键盘 `↑/↓/1–9` 快选与 6 色快捷色板自定义新建，默认不注册 Zotero 原生题名前彩色圆点标记并可在设置中按需开启同步，自动避开 Word 引用托管标签）、**「评级」**（`1–5 ⭐` 饱满原生星标连贯悬停预览、乐观即时点亮、不破坏多选批量打分，默认写入独立缓存 `item-ratings.json` 零污染文库，亦兼容读取或切换至 `Extra` 字段 `Rating: N` 或星标标签 `⭐`–`⭐⭐⭐⭐⭐`）、**「阅读时长」**（含微型进度条，点击展开页级停留热力柱并可一键直跳峰值页/上次页）、**「标注分布」**（按实际高亮色渲染比例堆叠条，点击展开色彩统计、批注预览直跳 PDF 与对比矩阵入口）与 **「简记」** 五大原生列（均内置 5,000 条级 LRU 缓存与防抖刷新）。
- **画廊视图与多维度拖拽看板 (`Gallery & Kanban Board`)**：
  - 在主文献库顶部工具栏提供 **「▦ 画廊/看板」** 一键切换按钮（亦支持 `Ctrl+P` Spotlight 唤起），采用 **原生 DOM 注入接管 + `MutationObserver` 显隐互斥守卫 + `ZoteroPane` 状态适配器**，与原生的多选（`Click` / `Ctrl+Click` / `Shift+Click` / 键盘方向键）、右键 `#zotero-itemmenu` 上下文菜单及双击打开无缝双向桥接；
  - 内置 **Fenwick 树高度索引虚拟滚动 (`GalleryHeightIndex`)** 与 **滚动空闲检测 (`scrollIdle`)**，配合 **离屏复用 Zotero 内置 `<attachment-preview>` 渲染首页封面 + 视口距离优先级队列 + `AbortController` 移出取消 + 文件 `[lastModified, size]` 与 `SHA-256` 指纹磁盘缓存**（自动清理过期与旧版缓存），支持 **瀑布流画廊网格** 与 **6 大维度分组看板**（跨列批量拖拽修改状态/星级、列头拖拽重排）在数千篇文献规模下流畅滚动。
- **分类级集中笔记与标注管理中心 (`Notes & Annotations Hub`)**：
  - 在主工具栏提供 **「≣ 笔记/标注」** 入口，支持在 **当前分类/视图**、**已选文献**、**已开阅读标签** 三档范围间实时切换；
  - **标注汇总页**：聚合全部 PDF 批注，支持一键忽略图表类标注（`Figure` / `Table`）、有个人评注时优先显示评注、五类英文语义筛选与布尔检索（`&&` / `||`）`<mark>` 高亮；
  - **笔记与简记页**：同屏汇总每篇文献的 Zotero 独立子笔记摘要与条目 **「简记」**（支持在弹窗内直接行内编辑简记并即时落盘至 `brief-notes.json`），支持一键切换文献对比矩阵、复制 Markdown 综述汇总或直接保存为当前分类下的 Zotero 笔记。
- **条目「简记」(Brief Note) 与跨文献标注对比矩阵**：
  - 在右侧「信息」面板顶部提供可直接内联编辑的 **「简记」** 行，可选双向同步至条目原生 `Extra` 字段（`BridgeFlow-Remark: ...`）；
  - 支持 PDF 多选跨页标注右键合并、选词弹窗自定义颜色数量（默认精简 5 色英文标签：Context、Method、Gap、Finding、Evidence，可在设置页一键切换 3 色 / 5 色 / 8 色或逐色自由勾选，未启用颜色自动隐藏不占弹窗空间），以及按颜色语义分列对比多篇文献批注的 **交互式对比矩阵**（支持导出 Zotero Note / Markdown / CSV / HTML 或批量插入 Word）。

### 3. 子系统三：侧栏引文预览、反查与 PDF 对照 (`inspector`)

- **CSL 实时预览**：在条目右侧栏即时生成文内引用与参考文献列表，支持切换样式、缩放字号/行距及一键复制富文本与纯文本。
- **紧凑引文反向逆查**：识别剪贴板或粘贴文本中的引文（支持作者、年份、期刊、卷期、页码、DOI、arXiv 与本地历史模糊比对），一键定位文库条目或直接跳转已打开的阅读器标签。
- **侧栏 PDF 缩略预览与同条目/相邻标签对照**：支持按页延迟渲染与远页 Canvas 内存回收、缩放、页码角标、双击直跳阅读器，以及在单条目的多 PDF 附件（正文 / Supporting Information）或主窗口「自身 / 左标签 / 右标签」间快速切换对照。
- **PDF 文件夹定位与原生轻卡片 Word 引用工作区**：一键在文件管理器选中 PDF；在右侧栏以贴近 Zotero 原生的轻卡片呈现文档连接状态、三列紧凑引用统计（已引用文献 / 文内引用 / 待找回）、当前选中文献一键插入与工作区分组联动，并提供断链引文核对找回与引用文献信息完整性提醒（按条目类型识别缺失字段与建议补全项，支持一键定位、忽略/撤销与恢复，不改动原文献与 Word 引文）。

### 4. 子系统四：Microsoft Word 引用追踪与标签治理 (`word-cite`)

- 在文献库展示原生 **「引用」** 序数列（优先读取 Citeproc 真实题录序号、回退稳定指纹留座去重，兼容多文档会话与出现频次统计），支持 Windows 原生拖拽直接插入可编辑 Word 引文域，配合事务回滚防呆与 90 秒命令卡死保护；
- **缺失/回收站引文智能找回与官方 `dc:replaces` 自动重连**：支持 Word 刷新后通过 URI 穿透找回 Zotero 回收站原条目（完整保留原 PDF 附件与批注），或从 Word 内嵌 CSL-JSON 备份单事务全 Schema 重建 / DOI 及无 DOI 精确题录查重复用，提供结构化多胶囊结果回执、逐条勾选、一键定位与多 Word 窗口防误刷守卫，并支持 `Ctrl+P` > 零选中兜底找回（严守外部账号 URI 隔离护栏）；
- 自动维护 Word 关联临时文集分类并置顶排序，按设定前缀（默认 `/Citations`）自动同步已引用文献标签，采用串行队列确保并发写作时不丢状态。

## 五大跨领域事件联动 (`src/bridges/`)

| Bridge 模块 | 协同能力 |
|---|---|
| `CopyHistoryBridge` | 从标签页右键、CSL 预览面板或 Spotlight 复制引文后自动沉淀至本地反查历史库 |
| `CiteBadgeBridge` | 将 Word 正在引用的条目标识与序数实时投射为垂直侧栏与悬停卡片的 `[N]` 徽标 |
| `LookupWorkspaceBridge` | 点击反查命中条目时优先激活并展开其在工作区中已打开的标签页及分组 |
| `SpotlightFusionBridge` | 通过 `Ctrl+P` > 命令一键归组当前 Word 正在引用的打开文献，或直接生成对比矩阵 |
| `VisualNotesBridge` | 将独立简记、阅读热力进度变化与 `Extra` 同步桥接至主文库列及信息面板 |

## 五路独立持久化缓存设计 (`bridgeflow-cache/`)

插件数据默认保存于 `<Zotero数据目录>/bridgeflow-cache/`（可在设置「存储维护」页指定自定义目录，重启生效），分为 `citations/`、`workspace/`、`reading/`、`ratings/` 和 `covers/` 子目录。工作区与历史等耐久数据使用独立 JSON 文件，均采用 `.tmp` 临时文件原子替换、`.bak.json` 上一版备份与串行写入队列。升级后从旧位置读取并写入新目录，旧文件保留。

| 独立文件 | 存放数据 | 安全隔离与性能原则 |
|---|---|---|
| `reading/brief-notes.json` | 条目 **简记** (`remarks`) 与标签备注模式 (`remarkModes`) | **人工内容最高安全级**：仅用户编辑简记时 240ms 防抖写入，绝不被 15 秒阅读遥测覆盖，也不受清空工作区或清空阅读时长影响；开启 `syncRemarkToExtra` 时双写 Zotero `Extra` 实现跨端原生同步。 |
| `ratings/item-ratings.json` | 文献 **星级评价** (`1–5 ★`，按 `libraryID:itemKey` 索引) | **零污染默认存储**：默认将星级评价写入本独立缓存，不修改 Zotero 原生 `Extra` 或标签；兼容读取旧版 `Extra`/星标评级，支持独立 JSON 导出与清空。 |
| `reading/reading-progress.json` | 累计阅读时长 (`readSeconds`)、热力图逐页停留 (`pageSeconds`)、`lastViewedAt` | 彻底脱离 `prefs.js`，避免大库配置膨胀；多端合并同一页按 `Math.max` 取大值安全融合。 |
| `workspace/workspace-snapshots.json` | 工作区标签分组、折叠/固定/休眠状态、虚拟成员、快照（同步镜像至 `workspace.document`） | 仅在布局与会话变化时写入；设置页清空工作区仅重置此文件，不伤及阅读时长、简记与星级评价。 |
| `citations/citation-history.json` | 复制与反向逆查引文历史 | 受独立的容量上限与保留天数 TTL 管理，按 `清空全部引文缓存` 独立清理。 |

- `covers/` 保存可重新生成的 PDF 首页缩略图。清理只移除插件识别的封面文件。
- **无缝自动迁移**：首次升级启动时，`initDiskCache()` 会自动将旧版混合在 `workspace-snapshots.json` / `workspace.document`（`<= v0.4.0`）以及 `reading-notes.json`（`v0.4.1`）中的历史数据无损迁移至 `reading-progress.json` 与 `brief-notes.json`。
- **独立备份与清理保护**：设置页「存储维护」选项卡提供独立的一键导出（阅读时长 JSON / 简记 Note JSON / 星级评价 JSON）及带二次确认的分类清理按钮。

## 设置中心

设置面板采用 **6 选项卡水平标签导航**（`总览` · `工作区` · `可视化与简记` · `检阅与反查` · `Word 引用` · `存储维护`），遵循 **16px / 40px 黄金对齐基准** 与纯 Fluent（`en-US` ↔ `zh-CN`）双语对称驱动：
- 仅「总览」首卡提供四大子系统独立热启停与联动总控，停用子系统时其所属设置页自动显示快速启用横幅；
- 修改配置即时保存生效，支持一键重置默认与诊断调试日志。

## 开发、架构守卫与构建验证

- **五层微内核结构**：`bootstrap.js` ➔ `src/kernel/` ➔ `src/services/` ➔ `src/domains/`（4 个独立子域禁止直接横向导入）➔ `src/bridges/`。
- **技术栈**：TypeScript `6.0.3`（`strict: true` / `tsc --noEmit`）、esbuild `0.28.2`（`minify: false` 保持源码可审计）、Valibot `1.5.0`。
- **架构与质量守卫**（`npm test` 强制前置执行）：包含单文件 `<= 360` 行上限、零 `@ts-ignore`/`@ts-nocheck`、五层依赖边界、全链路 8 处版本号对齐、`en-US` ↔ `zh-CN` Fluent 键值完全对称、`prefs.xhtml` 零硬编码中文、Zotero `10.0 ~ 12.*` API 合规等 **13 项静态守卫**与 **78 项单元测试**。

环境要求：Node.js `>= 22.14`、PowerShell（用于打包 `.xpi`）。

```bash
npm install
npm test
npm run build:xpi
```
