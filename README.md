# Zotero BridgeFlow（桥引）

> 当前版本：**0.4.3** · 兼容范围：**Zotero `10.0` ~ `12.*`** · 协议：**AGPL-3.0-or-later**

</div>

**Zotero BridgeFlow（桥引）** 是专为 **Zotero 10 ~ 12** 打造的一体化科研读写工作台插件，在微内核架构之上深度融合了 **多标签阅读工作区**、**阅读可视化与条目简记**、**侧栏引文预览 / 反向逆查 / PDF 对照** 与 **Microsoft Word 写作引用追踪**，全面打通 **「多篇沉浸精读 ➔ 批注矩阵对比与简记沉淀 ➔ 即时引文检阅/反查 ➔ Word 写作引用追踪」** 闭环。

---

## 核心功能全景

### 1. 子系统一：阅读工作区与快速查找 (`workspace`)

- **双模标签工作区**：
  - 顶部水平分组标签栏（支持滚轮横向滚动、`compact` / `auto` / `normal` 三态紧缩、分组双击内联改名、颜色切换、拖拽成组与 `Compact Top Bar`）；
  - 左侧可调宽垂直侧边栏（支持 `分组` / `集合` / `状态` 三视图切换、快捷键导航、批量管理、拖拽排序、Word 引用序数徽标 `[1]` 与阅读进度条）。
- **三态标签生命周期与会话快照**：支持固定标签页、空闲自动/手动休眠标签释放内存、保留分组虚拟成员；支持手动快照、模板快照与自动滚动快照，并通过中心弹窗（Hub）执行期刊/会议智能归组与工作区 JSON 导出/导入。
- **Spotlight 全局命令与快速查找 (`Ctrl+P` / `Cmd+P`)**：
  - 打开即展示最近标签、Word 正在引用的文献、最近关闭标签、会话快照与分组；输入后按标题、作者、备注、分组检索，输入 `>` 进入命令模式（如直达分组、一键将 Word 正在引用的打开文献生成对比矩阵等）。
  - 列表高度自适应当前窗口剩余可视空间，防按键清空白闪。
- **高精度阅读计时与悬停预览卡片**：
  - 在主窗口聚焦、激活阅读器标签且未进入 3 分钟键鼠/滚轮/翻页无操作空闲时，每 15 秒及切页/关页瞬间结算停留秒数（单跳 `30s` 封顶防止系统休眠漂移），切页尾数精准归属至刚离开的旧标签与对应页码；
  - 悬停标签显示相对阅读时间、精确当前页与时长（支持 `<60s` 秒级展示）、峰值停留页（`最常停留 Pxx`）、标注数量与按页阅读热力条。

### 2. 子系统二：阅读可视化、条目简记与文献对比矩阵 (`visual-notes`)

- **题名阅读热力图与文库列**：
  - 将论文全篇划分为最多 16 个分桶，根据逐页累计停留时长生成相对强度渐变色条叠加渲染在 Zotero 主列表题名后，支持自定义热力图基色、最大不透明度与选中行高亮反白，不修改 Zotero 原生题名字段；
  - 主文库支持开启 **「阅读时长」**、**「标注分布」** 与 **「简记」** 三个原生树状列（内置渐变/标注摘要有界缓存与防抖刷新，保持大库滚动流畅）。
- **条目「简记」(Brief Note)**：
  - 在右侧「信息」面板顶部提供可直接内联编辑的 **「简记」** 行，可选双向同步至条目原生 `Extra` 字段（`BridgeFlow-Remark: ...`），实现主库列表、标签页与信息侧栏一处修改全处联动。
- **PDF 阅读器增强与跨文献标注对比矩阵**：
  - 支持多选跨页标注右键 **「合并选中的标注」**（自动还原行尾连字符并合并批注说明）；
  - 在 PDF 选词/批注颜色弹窗按钮旁实时显示自定义语义名称（支持设置页 8 色胶囊所见即所得修改）；
  - **交互式对比矩阵**：从分组右键、Spotlight 或设置面板一键打开对比矩阵，按颜色语义维度分列对比多篇文献批注，支持维度计数过滤胶囊、布尔语法检索（`&&` / `||`）`<mark>` 高亮匹配、点击论文跳转自动收起弹窗，并可一键导出为 **Zotero 原生子笔记 Note**、Markdown、CSV、HTML 或直接批量插入 Word。

### 3. 子系统三：侧栏引文预览、反查与 PDF 对照 (`inspector`)

- **CSL 实时预览**：在条目右侧栏即时生成文内引用与参考文献列表，支持切换样式、缩放字号/行距及一键复制富文本与纯文本。
- **紧凑引文反向逆查**：识别剪贴板或粘贴文本中的引文（支持作者、年份、期刊、卷期、页码、DOI、arXiv 与本地历史模糊比对），一键定位文库条目或直接跳转已打开的阅读器标签。
- **侧栏 PDF 缩略预览与同条目/相邻标签对照**：支持按页延迟渲染与远页 Canvas 内存回收、缩放、页码角标、双击直跳阅读器，以及在单条目的多 PDF 附件（正文 / Supporting Information）或主窗口「自身 / 左标签 / 右标签」间快速切换对照。
- **PDF 文件夹定位与 Word 协同面板**：一键在文件管理器选中 PDF，或在右侧栏直览当前 Word 文档引文统计与分组联动入口。

### 4. 子系统四：Microsoft Word 引用追踪与标签治理 (`word-cite`)

- 在文献库展示原生 **「引用」** 序数列（多文档独立会话追踪与出现频次统计），支持 Windows 原生拖拽直接插入可编辑 Word 引文域，配合事务回滚防呆与 90 秒命令卡死保护；
- 自动维护 Word 关联临时文集分类并置顶排序，按设定前缀（默认 `/Citations`）自动同步已引用文献标签，采用串行队列确保并发写作时不丢状态。

## 五大跨领域事件联动 (`src/bridges/`)

| Bridge 模块 | 协同能力 |
|---|---|
| `CopyHistoryBridge` | 从标签页右键、CSL 预览面板或 Spotlight 复制引文后自动沉淀至本地反查历史库 |
| `CiteBadgeBridge` | 将 Word 正在引用的条目标识与序数实时投射为垂直侧栏与悬停卡片的 `[N]` 徽标 |
| `LookupWorkspaceBridge` | 点击反查命中条目时优先激活并展开其在工作区中已打开的标签页及分组 |
| `SpotlightFusionBridge` | 通过 `Ctrl+P` > 命令一键归组当前 Word 正在引用的打开文献，或直接生成对比矩阵 |
| `VisualNotesBridge` | 将独立简记、阅读热力进度变化与 `Extra` 同步桥接至主文库列及信息面板 |

## 四路独立持久化缓存设计 (`bridgeflow-cache/`)

插件数据默认保存于 `<Zotero数据目录>/bridgeflow-cache/`（可在设置「存储维护」页指定自定义目录，重启生效），**四类生命周期截然不同的数据严格拆分为独立 JSON 文件**，均采用 `.tmp` 临时文件原子替换、`.bak.json` 上一版备份、串行写入队列及 `Valibot` Schema 严格校验：

| 独立文件 | 存放数据 | 安全隔离与性能原则 |
|---|---|---|
| `brief-notes.json` | 条目 **简记** (`remarks`) 与标签备注模式 (`remarkModes`) | **人工内容最高安全级**：仅用户编辑简记时 240ms 防抖写入，绝不被 15 秒阅读遥测覆盖，也不受清空工作区或清空阅读时长影响；开启 `syncRemarkToExtra` 时双写 Zotero `Extra` 实现跨端原生同步。 |
| `reading-progress.json` | 累计阅读时长 (`readSeconds`)、热力图逐页停留 (`pageSeconds`)、`lastViewedAt` | 彻底脱离 `prefs.js`，避免大库配置膨胀；多端合并同一页按 `Math.max` 取大值安全融合。 |
| `workspace-snapshots.json` | 工作区标签分组、折叠/固定/休眠状态、虚拟成员、快照（同步镜像至 `workspace.document`） | 仅在布局与会话变化时写入；设置页清空工作区仅重置此文件，不伤及阅读时长与简记。 |
| `citation-history.json` | 复制与反向逆查引文历史 | 受独立的容量上限与保留天数 TTL 管理，按 `清空全部引文缓存` 独立清理。 |

- **无缝自动迁移**：首次升级启动时，`initDiskCache()` 会自动将旧版混合在 `workspace-snapshots.json` / `workspace.document`（`<= v0.4.0`）以及 `reading-notes.json`（`v0.4.1`）中的历史数据无损迁移至 `reading-progress.json` 与 `brief-notes.json`，并自动净化旧快照文件。
- **独立备份与清理保护**：设置页「存储维护」选项卡提供独立的一键导出（阅读时长 JSON / 简记 Note JSON）及带二次确认的分类清理按钮。

## 设置中心

设置面板采用 **6 选项卡水平标签导航**（`总览` · `工作区` · `可视化与简记` · `检阅与反查` · `Word 引用` · `存储维护`），遵循 **16px / 40px 黄金对齐基准** 与纯 Fluent（`en-US` ↔ `zh-CN`）双语对称驱动：
- 仅「总览」首卡提供四大子系统独立热启停与联动总控，停用子系统时其所属设置页自动显示快速启用横幅；
- 修改配置即时保存生效，支持一键重置默认与诊断调试日志。

## 开发、架构守卫与构建验证

- **五层微内核结构**：`bootstrap.js` ➔ `src/kernel/` ➔ `src/services/` ➔ `src/domains/`（4 个独立子域禁止直接横向导入）➔ `src/bridges/`。
- **技术栈**：TypeScript `6.0.3`（`strict: true` / `tsc --noEmit`）、esbuild `0.28.2`（`minify: false` 保持源码可审计）、Valibot `1.5.0`。
- **架构与质量守卫**（`npm test` 强制前置执行）：包含单文件 `<= 360` 行上限、零 `@ts-ignore`/`@ts-nocheck`、五层依赖边界、全链路 8 处版本号对齐、`en-US` ↔ `zh-CN` Fluent 键值完全对称、`prefs.xhtml` 零硬编码中文、Zotero `10.0 ~ 12.*` API 合规等 **13 项静态守卫**与 **50 项单元测试**。

环境要求：Node.js `>= 22.14`、PowerShell（用于打包 `.xpi`）。

```bash
npm install
npm test
npm run build:xpi
```
